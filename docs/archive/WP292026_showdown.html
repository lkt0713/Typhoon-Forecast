How to read this

Drawn when the storm ended. Track error (km) by forecast lead, homogeneous sample: every model is scored on the same forecasts, against the JTWC warning positions  ·  Overall = how far behind the best model each one was, averaged over 24–120 h, so the long leads with big errors do not decide it alone  ·  Intensity |e| = mean absolute wind error (bias: + too strong, − too weak)  ·  Official forecasts are ranked only among themselves, each checked against its own positions, on the forecasts all of them issued
